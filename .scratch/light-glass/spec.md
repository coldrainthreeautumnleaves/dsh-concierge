# 轻玻璃：会话区不再整块模糊

Status: ready-for-agent

## 背景

玻璃皮肤把 `backdrop-filter` 挂在 `[data-conversation-region]` 上。会话区是流式输出时
唯一持续重绘的大面积层：每来一段文字，浏览器都要重新采样它背后的壁纸再跑一遍模糊核，
4K 屏上这一块的采样面积最大，是最贵的一刀。

上一轮已经做过三件事：颗粒从全屏伪元素挪进壁纸层（不再每帧重混一层）、`[data-slot]`
从模糊列表里摘掉、半径 20/26px 降到 14/18px。剩下的最大一块就是会话区本身。

## 目标

- 新增「轻玻璃」开关（默认关），打开后 `[data-conversation-region]` 完全去掉
  `backdrop-filter`。
- 菜单、对话框、卡片、提示这些浮层保持原有模糊：壁纸清晰 + 面板半透明 + 浮层毛玻璃，
  玻璃感还在，只是会话区不再整块重糊。
- 只在玻璃皮肤下出现；切到别的皮肤或关掉外观时不留残留。
- 状态进 `dsh-concierge:look`，刷新 / 重启后保持。

## 非目标

- 不动透明度、颗粒滑杆的语义，不动壁纸路由。

## 行为

| 状态 | 会话区 | 浮层（菜单 / 对话框 / 卡片 / 提示） |
| ---- | ------ | ----------------------------------- |
| 玻璃 + 轻玻璃关（默认） | `blur(14px) saturate(160%) brightness(1.03)` | 保持 |
| 玻璃 + 轻玻璃开 | 无 `backdrop-filter` | 保持 |
| 非玻璃皮肤 / 外观关闭 | 无 | 无 |

## 验收

1. 设置 → 工具 → 外观，玻璃皮肤下出现「轻玻璃」开关，默认关。
2. 打开后 `document.documentElement.dataset.dshGlassLight === '1'`，会话区
   `getComputedStyle(...).backdropFilter === 'none'`。
3. 关掉开关，会话区恢复 `blur(14px)`。
4. 切到别的皮肤 / 关掉外观：`data-dsh-glass-light` 消失，无残留。
5. `node --check client.js` 通过。

## 风险

- 会话区底色本来就半透明，去掉模糊后壁纸的色块会直接透出来；深色壁纸下要确认正文
  对比度仍然够（这是开关，不满意可以关掉，不改默认行为）。
- 开关打开时 `applyLook` 会重新 `overrideTokens` 一次，切换有一次性重绘成本，可接受。
