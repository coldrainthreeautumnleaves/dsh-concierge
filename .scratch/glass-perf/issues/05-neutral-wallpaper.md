# 05 预设壁纸换成冷调低饱和

Status: ready-for-agent

## 问题

玻璃皮肤的面板是半透明的，壁纸的色相会直接染到面板上。旧的预设是靛蓝 / 粉 / 青 / 黄
四色相拼，截图取色：聊天区中部 `#f6f5ed`（偏黄）、右上 `#f6dfed`（粉）、右缘 `#f0f9fb`
（青），顶部标题栏左侧 `#e2e5f0` 而右侧 `#f3eff9`——文字底下是彩色，顶栏也不均匀。

## 改法

- 浅色：三团大而软的灰蓝（`rgba(186,200,224,.55)` / `rgba(200,202,224,.45)` /
  `rgba(184,206,214,.45)`）+ 冷灰底 `#f2f5fa → #edf1f7 → #f4f7fb → #f9fbfd`。
- 深色：同一结构，换成 `rgba(60,74,106,.55)` / `rgba(66,66,96,.45)` /
  `rgba(40,72,88,.5)` + `#12171f → #131a24 → #101720 → #0b1017`。
- 色块直径放大到 860–1000px，位置保持在角落，让面板底下只是缓和的明暗，不是彩色团。

## 怎么算做完
